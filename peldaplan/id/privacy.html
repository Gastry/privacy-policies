2. Data yang diolah di perangkat

Aplikasi menggunakan ukuran dan nama yang Anda masukkan, proyek, hingga sepuluh versi sebelumnya per proyek, serta satuan yang dipilih. Data disimpan secara lokal di penyimpanan pribadi aplikasi Android. Laporan dan cadangan sementara juga disiapkan di sana. Hindari memasukkan informasi pribadi yang tidak diperlukan dalam nama atau file.

Privasi

PeldaPlan tidak menyertakan iklan, analitik, atau server sendiri. Aplikasi menggunakan internet untuk sinkronisasi Google Drive opsional dan verifikasi pembelian Google Play. Akun yang dipilih dan status sinkronisasi disimpan di perangkat; Google mengelola izin dan pembelian. Penerbit tidak menerima proyek atau kredensial. PeldaPlan tidak menambahkan enkripsi sendiri.

4. File yang Anda pilih untuk diekspor atau diimpor

Saat mengekspor PDF, SVG, CSV, atau JSON, Anda memilih tujuan melalui pemilih file Android. Jika memilih penyedia cloud seperti Google Drive, atau kemudian membagikan file, penyedia tersebut dapat mengolah data sesuai ketentuannya sendiri. Pilihan itu tidak mengaktifkan sinkronisasi milik PeldaPlan. Impor membaca dan memvalidasi file pilihan Anda sebelum menambahkan salinan lokal proyek.

5. Penyimpanan, keamanan, dan penghapusan

Proyek tetap berada di perangkat sampai Anda menghapusnya, mengosongkan daftar, menghapus data aplikasi, atau mencopot aplikasi. Menghapus proyek juga menghapus versi lokalnya. Preferensi dan file sementara pribadi dihapus saat data aplikasi dihapus atau aplikasi dicopot. Cadangan yang diekspor tetap berada di tempat penyimpanan pilihan Anda dan harus dihapus secara terpisah. Versi ini menonaktifkan pencadangan otomatis dan transfer perangkat yang dikelola Android. Perlindungan mengandalkan isolasi penyimpanan pribadi dan keamanan perangkat, tanpa enkripsi basis data tambahan atau jaminan pemulihan tanpa cadangan eksternal.

6. Permintaan dukungan secara sukarela

Jika Anda mengirim email, penerbit menerima alamat, isi pesan, dan lampiran yang Anda pilih untuk menjawab serta menangani permintaan. Dukungan menggunakan Gmail dan juga tunduk pada ketentuan layanan tersebut. Informasi disimpan selama diperlukan untuk menangani pertanyaan dan memenuhi kewajiban hukum, lalu dihapus ketika tidak lagi diperlukan. Jangan kirim kata sandi, kunci, atau file berisi data pribadi yang tidak diperlukan.

7. Situs ini dan layanan eksternal

Dokumentasi dihosting di GitHub Pages. Saat situs dibuka, GitHub dapat mengolah alamat IP dan data teknis permintaan sesuai kebijakan privasinya. Situs ini tidak menambahkan analitik, iklan, formulir, font jarak jauh, atau cookie nonesensial miliknya sendiri. Tautan ke GitHub, Google Play, email, atau otoritas membuka layanan dengan kebijakan masing-masing; bukan layanan pelacakan yang tertanam di PeldaPlan.

8. Hak dan kendali atas data Anda

Data proyek hanya ada di perangkat atau cadangan yang Anda buat, sehingga penerbit tidak dapat melihat atau menghapusnya dari jarak jauh. Kelola melalui Proyek dan pengaturan Android. Untuk data yang dikirim ke dukungan, Anda dapat meminta akses, perbaikan, penghapusan, mengajukan keberatan, atau meminta pembatasan maupun portabilitas jika berlaku, melalui thegastry@gmail.com. Anda juga dapat mengadu kepada Badan Perlindungan Data Spanyol atau otoritas pengawas yang berwenang. Penerbit tidak melakukan pengambilan keputusan otomatis atau pemrofilan.

Sinkronisasi dengan Drive

Sinkronisasi Google Drive memerlukan PRO dan harus diaktifkan secara tegas oleh pengguna. PRO adalah pembelian satu kali melalui Google Play tanpa perpanjangan otomatis; harga dan ketentuan ditampilkan sebelum konfirmasi. Ketersediaannya bergantung pada toko dan instalasi ini. Anda dapat menonaktifkan sinkronisasi dengan tetap menyimpan data lokal dan salinan di Drive. Pemulihan tidak dijamin jika unggahan belum selesai. Simpan juga cadangan eksternal. Google mengelola penyimpanan dan pembelian sesuai ketentuan dan kebijakan privasinya.

Pilih tindakan untuk penghapusan berikutnya. Mengubah pengaturan ini tidak memengaruhi penghapusan sebelumnya atau cadangan JSON yang diekspor.

Android menentukan kapan sinkronisasi latar belakang dijalankan. Tanpa koneksi, ruang kosong di Drive, atau izin akses, perubahan akan menunggu. Periksa sinkronisasi terakhir sebelum menghapus aplikasi atau mengganti ponsel, dan simpan cadangan lokal.

Akses ke Google Drive dan Google Play

Saat Anda mengaktifkan sinkronisasi, PeldaPlan hanya meminta izin drive.appdata. Proyek tersimpan beserta hingga sepuluh versi sebelumnya dikirim melalui HTTPS ke folder PeldaPlan yang bersifat pribadi dan tersembunyi di Drive Anda. Izin ini tidak memungkinkan aplikasi menelusuri file Anda yang lain. Aplikasi menyimpan alamat email akun yang dipilih dan pengenal turunan akun di perangkat untuk memisahkan data antar-akun. Proyek tidak dikirim ke server penerbit.

Jika Anda memilih untuk menyinkronkan penghapusan, versi terkait akan dihapus dari Drive setelah sinkronisasi selesai. Penanda teknis penghapusan tanpa isi proyek dapat tetap disimpan agar perangkat lain tidak memulihkan proyek yang telah dihapus secara tidak sengaja. Jika Anda memilih untuk menyimpannya di Drive, menghapus proyek di perangkat tidak akan menghapusnya dari Drive. Menonaktifkan sinkronisasi atau menghapus instalasi aplikasi tidak otomatis menghapus data di Drive. Anda dapat mencabut akses melalui Akun Google Anda.

Google Play menangani pembayaran. PeldaPlan menyimpan bukti pembelian dan status lisensi untuk memverifikasi serta memulihkan PRO; aplikasi tidak menerima nomor kartu. Penerbit tidak menjual data ini atau menggunakannya untuk iklan. Cadangan JSON yang diekspor secara manual terpisah dari sinkronisasi.
