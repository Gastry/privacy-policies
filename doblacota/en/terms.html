What the app does

Doblacota is a geometric calculation tool for planning and checking pipe and conduit layouts. It provides five methods, metric and imperial units, reference data, formulas and a local history. It does not certify designs or verify regulatory compliance.

Using the results

Check dimensions, units, the physical radius and equipment compatibility before using a calculation on site. Tables are identified as reference data; calculated wall thickness is distinguished from the listed value. The geometric model uses a consistent centerline radius and rejects dimensions with no physical solution within the supported range. It does not model material springback. Compatibility with every real tool is not guaranteed.
